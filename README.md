# Numerical Algorithms Projects

This repository contains six projects focused on numerical analysis and scientific computing in Python.
Each project includes implementations, tests, and supporting technical report material.
Topics span linear algebra, nonlinear equations, interpolation/integration, and ODE-based modeling.

1. **P1 - Intro to Numerical Methods**  
   Foundational numerical analysis exercises in Python, with tested implementations and a written report.

2. **P2 - Applied Numerical Computation**  
   Practical numerical algorithms focusing on approximation, stability, and performance, with unit tests and documentation.

3. **P3 - Matrix Factorizations and Image Compression**  
   Linear algebra methods including Householder transforms, bidiagonalization, and QR-based workflows applied to image compression.

4. **P4 - Nonlinear Equations and Dynamical Systems**  
   Numerical root-finding and modeling with Bairstow, Newton-Raphson, and Lagrangian point computations.

5. **P5 - Aerodynamic Data Processing and Numerical Integration**  
   Airfoil-oriented scientific computing with spline interpolation, pressure analysis, and numerical integration tools.

6. **P6 - ODE Solvers and Physical/Chemical Models**  
   Differential equation solvers (Euler, Heun, Midpoint, RK4) applied to pendulum motion, Lotka-Volterra, and reaction kinetics.
